# 📱 TG Notifier — iOS Приложение для Telegram (.IPA)

Красивое iOS-приложение (в стиле iOS 18 Glassmorphic), которое подключается к Telegram по безопасному протоколу MTProto, отслеживает в реальном времени входящие сообщения и отображает точное количество новых непрочитанных уведомлений.

---

## ✨ Возможности

- 🔐 **Полноценная авторизация в Telegram**: вход по номеру телефона, официальному коду подтверждения и 2FA паролю.
- 🔴 **Живой счетчик новых уведомлений**: мгновенно показывает общее число непрочитанных сообщений со светящимся iOS-бейджем.
- 📊 **Категории чатов**: раздельный подсчет для личных диалогов, групп, каналов и упоминаний (`@username`).
- ⚡ **Синхронизация в реальном времени**: при прочтении сообщений в официальном приложении Telegram счетчик автоматически уменьшается.
- 🔔 **Звук и вибрация iOS**: реалистичный звук уведомлений Apple (Tri-Tone / Chime) и Taptic Engine вибрация.
- 🧪 **Тестовый режим**: симуляция входящих уведомлений для проверки интерфейса и звука.
- 📲 **Сборка в `.ipa`**: проект адаптирован под iOS через Capacitor и готов к установке на iPhone/iPad.

## 🚀 Быстрый запуск на компьютере (Web / Preview)

1. Установите зависимости:
   ```bash
   npm install
   ```

2. Запустите локальный сервер разработки:
   ```bash
   npm run dev
   ```

3. Откройте в браузере: [http://localhost:5173](http://localhost:5173).

## 📦 Как получить готовый `.IPA` файл

### Способ 1: Автоматическая сборка через GitHub (Без компьютера Mac!)
1. Создайте репозиторий на [GitHub](https://github.com) и загрузите файлы этого проекта.
2. В репозитории откройте вкладку **Actions** -> **Build iOS IPA** -> нажмите **Run workflow**.
3. GitHub в облаке на сервере macOS автоматически соберет файл `TG-Notifier.ipa`.
4. Скачайте готовый `.ipa` из раздела **Artifacts**!

---

### Способ 2: Сборка на macOS через Xcode
Если у вас есть Mac с установленным Xcode:
```bash
# 1. Собрать веб-бандл
npm run build

# 2. Синхронизировать с iOS
npx cap sync ios

# 3. Открыть проект в Xcode
npx cap open ios
```
В Xcode выберите ваше устройство или симулятор и нажмите **Product -> Archive** для экспорта `.ipa`.

## 📲 Как установить `.ipa` на iPhone / iPad

Вы можете установить полученный `.ipa` файл любым удобным способом:
- **TrollStore** (для устройств с поддержкой) — мгновенная установка без ограничений по сертификатам.
- **Sideloadly** (Windows / macOS) — простая установка через USB кабель с бесплатным Apple ID.
- **AltStore** (Windows / macOS) — установка и автопродление по Wi-Fi.
- **Scarlet / Esign** — прямая установка на iPhone без ПК.

## 🛠 Технологический стек

- **Frontend**: React 18, TypeScript, Vite, Modern CSS Glassmorphism
- **Telegram Engine**: GramJS (MTProto Client WebSocket)
- **Mobile Wrapper**: Capacitor 6 iOS (`@capacitor/core`, `@capacitor/ios`, `@capacitor/haptics`, `@capacitor/local-notifications`)
- **Audio**: Web Audio API Chime Synth + Haptics
